# Prototype site

Three pages of plain HTML, CSS and JavaScript. No build step.

- `index.html` is the home page, linking to the two prototypes.
- `statistics/` is the short statistics prototype.
- `practice/` is the short practice prototype.

To put it online with GitHub Pages: upload everything in this folder to a public repository
(so `index.html` is at the top level), then Settings > Pages > Deploy from a branch > `main` / `(root)`.
